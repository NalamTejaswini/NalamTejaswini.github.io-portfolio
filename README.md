# Tejaswini Nalam – Portfolio Website

A clean, modern, single-page portfolio built with pure HTML & CSS.

## How to use

### 1. Preview locally
Just open `index.html` in your browser.

### 2. Host for free on GitHub Pages (Recommended)

1. Create a new repository on GitHub (example name: `portfolio` or `NalamTejaswini.github.io`)
2. Upload these files (`index.html`, `styles.css`, `README.md`)
3. Go to **Settings → Pages**
4. Under "Source", select the `main` branch and `/ (root)`
5. Click Save

Your live site will be available at:
`https://nalamtejaswini.github.io/`  
(or `https://nalamtejaswini.github.io/portfolio/` if the repo is not named `username.github.io`)

### 3. Alternative free hosting
- [Netlify Drop](https://app.netlify.com/drop) – just drag the folder
- [Vercel](https://vercel.com) – connect the GitHub repo

## Customization tips

- Update project descriptions or add more projects in `index.html`
- Change colors in `styles.css` under `:root`
- Add a profile photo later if you want (I can help with that)
- Keep the LeetCode / GitHub / LinkedIn links up to date
